# Cubase 鼠标修饰键 —— 逐条清单

共 37 条，覆盖 11 个上下文。


## 事件上（单击）

`Media item left click`

| 修饰键 | 行为 |
|---|---|
| 无 | `Select item` |
| Ctrl | `Toggle item selection` |

## 事件上（拖动）

`Media item left drag`

| 修饰键 | 行为 |
|---|---|
| 无 | `Move item` |
| Ctrl | `Move item ignoring snap` |
| Alt | `Copy item` |
| Ctrl+Alt | `Copy item ignoring snap` |

## 空白处（单击）
